# ⏰ Alarm Clock

A simple and interactive **Alarm Clock web application** built using **HTML, CSS, JavaScript, Python, and Flask**.

The application displays a live clock, allows the user to set an alarm, and plays an alarm sound when the selected time is reached.

---

## 🚀 Features

- 🕐 Live digital clock
- ⏰ Set an alarm using a time input
- 🔔 Alarm notification when the selected time is reached
- 🔊 Plays an MP3 alarm sound
- 💬 Displays an alarm message on the webpage
- 🎨 Custom CSS styling
- 🌐 Flask backend
- 📱 Simple and user-friendly interface

---

## 🛠️ Technologies Used

- **HTML** – Structure of the webpage
- **CSS** – Styling and layout
- **JavaScript** – Live clock, alarm logic, and audio playback
- **Python** – Backend programming
- **Flask** – Connects the Python backend with the frontend
